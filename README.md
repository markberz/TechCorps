# TechCorps Store

A premium, high-performance e-commerce storefront for next-gen computing hardware. This project features a modern dark-themed UI, interactive 3D models, and a fully functional shopping experience.

## 🚀 Features

- **Interactive 3D Experience**: Uses Google's `<model-viewer>` to display a high-quality `.glb` gaming laptop model.
- **Dynamic Product Catalog**: Products are rendered dynamically from a JSON-like object with filtering for Laptops and Desktops.
- **Advanced Search**: Real-time search functionality that scans product names and technical specifications.
- **Shopping Cart**: A persistent cart drawer that calculates totals in Philippine Peso (₱).
- **Fully Responsive**: Optimized for mobile, tablet, and desktop using Tailwind CSS.
- **Support Integration**: Quick links for Gmail support and an external Knowledge Base.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS
- **Logic**: Vanilla JavaScript (ES6+)
- **Icons**: Lucide Icons
- **3D Engine**: Google Model Viewer

## 📦 Installation

1. Clone the repository.
2. Open the project folder in VS Code and use the **Live Server** extension to view the site (required for 3D model loading).
